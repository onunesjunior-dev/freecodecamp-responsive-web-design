# Nutrition Label

Oficina do Módulo 15 (Tipografia) — 68 passos. Rótulo nutricional fiel ao padrão
da FDA americana, construído com `display: flex; justify-content: space-between;`
em cada linha pra alinhar nutriente/valor nas pontas, e `:not(.no-divider)` pra
aplicar divisórias em lote sem repetir regras.
