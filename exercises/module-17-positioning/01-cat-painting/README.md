# Cat Painting

Oficina do Módulo 17 (Posicionamento) — 80 passos. Rosto de gato desenhado só com
divs posicionadas em `position: absolute`, triângulos puros via bordas
transparentes, `border-radius` assimétrico pra formas orgânicas e `transform:
rotate()` pra orelhas, bigodes e boca. Centralização perfeita no body via
`top/right/bottom/left: 0` + `margin: auto`.
