# Colored Box Set

Oficina do Módulo 14 (Flexbox) — 43 passos. Seis caixas coloridas num flex
container, cada uma com seu próprio `order`, `flex-grow` e `flex-shrink`
individuais — demonstra como a ordem visual pode ser desacoplada da ordem no DOM
e como grow/shrink/basis controlam a distribuição de espaço.
