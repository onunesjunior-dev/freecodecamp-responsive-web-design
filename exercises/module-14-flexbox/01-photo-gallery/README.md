# Photo Gallery

Oficina do Módulo 14 (Flexbox) — 22 passos. Galeria de fotos responsiva com
`display: flex` + `flex-wrap: wrap` + `gap`, sem media queries — as imagens se
reorganizam naturalmente conforme o espaço disponível. Usa `object-fit: cover`
pra evitar distorção e um `::after` fantasma pra alinhar a última linha.
