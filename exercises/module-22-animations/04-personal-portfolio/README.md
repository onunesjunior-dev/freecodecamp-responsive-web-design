# Personal Portfolio

Laboratório do Módulo 22 (Animações) — 12 testes. Página de portfólio pessoal
com navbar fixa (`backdrop-filter: blur`), seção de boas-vindas em 100vh,
grid de projetos responsivo (`repeat(auto-fit, minmax())`) e seção de contato,
com breakpoint em 768px exigido pelos testes oficiais.
