# City Skyline

Oficina do Módulo 20 (Variáveis CSS) — 115 passos. Skyline de cidade construído
inteiramente com gradientes CSS (`linear-gradient`, `radial-gradient`,
`repeating-linear-gradient`) e custom properties (`--building-color*`,
`--window-color*`) centralizadas no `:root`. Usa uma media query que
redefine as variáveis globais pra transformar o céu de dia em noite, sem tocar
em nenhuma regra individual de prédio.
