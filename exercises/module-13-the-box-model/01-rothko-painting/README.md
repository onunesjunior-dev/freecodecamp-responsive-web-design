# Rothko Painting

Oficina do Módulo 13 (O Modelo de Caixa) — 44 passos. Pintura abstrata no estilo
Rothko construída só com divs, `border-radius` assimétrico, `box-shadow` e
micro-rotações (`transform: rotate()`) pra simular pinceladas orgânicas. Usa
`overflow: hidden` no container pra criar um Block Formatting Context e conter o
margin collapse do filho sem alterar a geometria da caixa.
