Introduction

JavaScript is a versatile, high-level programming language that conforms to the ECMAScript specification.

Modern web development relies heavily on ECMAScript standards to deliver interactive client-side applications.

const greeting = "Hello, World!";
Variables and Constants

ES6 introduced block-scoped variable declarations using let and const.

Unlike var, let and const prevent accidental hoisting anomalies and redeclarations.

let counter = 0; const MAX_USERS = 100;
  • Use const by default for immutable bindings.
  • Use let only when variable reassignment is necessary.
Arrow Functions

Arrow functions provide a compact syntax for writing function expressions in modern JavaScript.

They do not have their own this, arguments, super, or new.target bindings.

const add = (a, b) => a + b;
  • Lexical this binding makes them ideal for callbacks.
Destructuring Assignment

The destructuring assignment syntax allows unpacking values from arrays or properties from objects into distinct variables.

This syntax makes extracting nested properties clean and concise.

const { id, title } = book; const [first, second] = items;
  • Supports default fallback values.
  • Allows property aliasing during extraction.
Promises and Async Await

Promises represent the eventual completion or failure of an asynchronous operation.

The async and await keywords allow asynchronous, promise-based behavior to be written in a cleaner, synchronous style.

async function fetchData(url) { const res = await fetch(url); return res.json(); }
CSS Media Queries

Media queries are a core component of responsive web design that inspect user-agent characteristics.

They allow layouts to adapt fluidly across devices ranging from mobile screens to ultra-wide desktop monitors.

@media (max-width: 768px) { #navbar { position: relative; } }
  • Inspect width, height, orientation and user preferences.
